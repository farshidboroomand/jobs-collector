# 🚧 Jobs Collector

> **⚠️ This project is currently under heavy construction.**  
> Architecture, APIs, and features may change frequently.

A Golang service that crawls **LinkedIn jobs** using user-defined bots.  
Bots watch specific queries and continuously collect job listings.

---

## Status

🚧 **Work in Progress**

Current development stage:
- Basic Go service structure
- MySQL integration
- Docker environment
- Initial Helm chart for Kubernetes

Planned next:
- Bot scheduler
- Concurrent job collectors
- Kafka event streaming
- Search indexing
